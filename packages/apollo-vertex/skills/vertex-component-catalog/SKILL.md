# Apollo Vertex component catalog

Import every name below from `@uipath/apollo-vertex`. Follow the
`use-vertex-components` skill for how to use and adapt them.

## Actions

- **Button**: Displays a button or a component that looks like a button. Exports: `Button`, `buttonVariants`.
  - Use when the user triggers an action, such as submitting a form, saving or opening a dialog.
  - Avoid when the control turns a setting on or off. Use **Switch** instead.
  - Avoid when the user picks one of a few modes or views. Use **Toggle Group** instead.
- **Button Group**: Groups multiple buttons together with proper styling and spacing. Exports: `ButtonGroup`, `ButtonGroupSeparator`, `ButtonGroupText`, `buttonGroupVariants`.
- **Toggle**: A two-state button that can be either on or off. Exports: `Toggle`, `toggleVariants`.
- **Toggle Group**: A set of two-state buttons that can be toggled on or off. Exports: `ToggleGroup`, `ToggleGroupItem`.

## Overlays

- **Dialog**: A modal dialog that appears in front of app content to provide critical information. Exports: `Dialog`, `DialogClose`, `DialogContent`, `DialogDescription`, `DialogFooter`, `DialogHeader`, `DialogOverlay`, `DialogPortal`, `DialogTitle`, `DialogTrigger`.
  - Use when the user must finish or dismiss a short, focused task before returning to the page, such as a small form or a single choice.
  - Avoid when the content is a long form or a record's details, or the user needs to keep the page in view. Use **Sheet** instead.
  - Avoid when the user confirms a destructive or irreversible action. Use **Alert Dialog** instead.
  - Avoid when the content is a few extra controls or details anchored to a trigger. Use **Popover** instead.

        </DialogHeader>

## Feedback

- **Alert**: Displays a callout for user attention. Exports: `Alert`, `AlertDescription`, `AlertTitle`, `alertVariants`.
  - Use when feedback must stay visible in context, such as validation errors, warnings or a blocking error.
  - Use when the user must act on the message, or the system raised it without a user action. With no related UI to anchor it to, show it as a persistent full-width banner below the main header.
  - Avoid when the message only confirms that an action the user just took succeeded. Use **Sonner** instead.
- **Sonner**: An opinionated toast component for React. Exports: `apolloToastClassNames`, `Toaster`.
  - Use when the message briefly confirms an action the user just took and asks nothing of them, such as "Changes saved".
  - Avoid when the message is a blocking error or a validation error, needs user input, or was raised by the system without a user action. Use **Alert** instead.

    ```tsx
    // Render <Toaster /> once in the root layout. toast comes from the sonner package.
    import { Toaster } from "@uipath/apollo-vertex";
    import { toast } from "sonner";

    <Toaster />

    toast.success("Changes saved", { description: "Your updates have been applied." });
    ```

- **Empty**: An empty state component for when there is no data to display. Exports: `Empty`, `EmptyContent`, `EmptyDescription`, `EmptyHeader`, `EmptyMedia`, `EmptyTitle`.
  - Use when a list, table, search result or page has nothing to show. Say why it is empty and offer the next action when there is one.
  - Avoid when the content is still loading. Use **Skeleton** instead.
  - Avoid when loading the content failed. Use **Alert** instead.
- **Skeleton**: Use to show a placeholder while content is loading. Exports: `Skeleton`.
- **Spinner**: A loading spinner component to indicate loading state. Exports: `Spinner`.
- **Progress**: Displays an indicator showing the completion progress of a task. Exports: `Progress`.
- **Confidence Signal**: A single chip for communicating AI confidence — used everywhere the system needs to say "can you act on this, or should you pause?" Exports: `ConfidenceSignal`, `SignalBars`.
