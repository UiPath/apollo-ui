# Apollo Vertex Theme

Apollo Vertex design system tokens — colors, typography, spacing, shadows, and easing functions with light and dark mode support.

## Installation

```bash
npx shadcn@latest add @uipath/apollo-vertex-theme
```

This will update your global CSS file (the `tailwind.css` path in `components.json`) with all Apollo Vertex design tokens for both light and dark mode.

## Updating

Re-run the same command to pull the latest token values.
