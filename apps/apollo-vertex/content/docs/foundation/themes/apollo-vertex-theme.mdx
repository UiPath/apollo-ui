---

## Installation

The theme ships with `@uipath/apollo-vertex`. Importing `tailwind.css` from your app's CSS includes it, along with Tailwind and the component styles:

```css
@import "@uipath/apollo-vertex/tailwind.css";
```

To use only the design tokens for both light and dark mode, import `theme.css` instead:

```css
@import "@uipath/apollo-vertex/theme.css";
```

## Updating

Update `@uipath/apollo-vertex` to get the latest token values.
