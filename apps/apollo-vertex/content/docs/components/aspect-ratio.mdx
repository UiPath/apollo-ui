## Usage

```tsx
import { AspectRatio } from "@uipath/apollo-vertex"
```

```tsx
<AspectRatio ratio={16 / 9}>
  <img src="..." alt="Image" className="object-cover" />
</AspectRatio>
```

## Common Ratios

- **16:9** - Standard video format
- **4:3** - Traditional TV format
- **1:1** - Square format
- **21:9** - Ultra-wide format
