## View

`KpiChart` renders a static label/value pair. Format the value yourself (this component just prints it).

```tsx
import { KpiChart } from "@uipath/apollo-vertex";

<KpiChart label="Total revenue" value="$342,000" />
```

### Props

- `label: string` — small text shown above the value.
- `value: string` — formatted display value.

## With adapter

`KpiChartWithAdapter` runs a single aggregate query and renders the result with `formatMetricValue` from charts-core (which respects the metric's expression and field type).

Pass one of the ready-made adapters, `dataFabricAdapter` or `insightsAdapter`, or implement the `DataAdapter` interface yourself:

```tsx
import { KpiChartWithAdapter, dataFabricAdapter } from "@uipath/apollo-vertex";

const adapter = dataFabricAdapter({
  baseUrl: "/api/datafabric/.../api",
  accessToken,
  entityName: "Orders",
});

const dataModel = {
  id: "total-revenue",
  metrics: [
    {
      id: "revenue",
      display: "Total revenue",
      expression: {
        type: "aggregate" as const,
        aggregation: "SUM" as const,
        argument: {
          id: "Amount",
          display: "Amount",
          type: "currency" as const,
          format: { currency: "USD" },
        },
      },
    },
  ],
};

const configuration = {
  id: "revenue-kpi",
  name: "Total revenue",
  type: "kpi" as const,
  metrics: ["revenue"],
};

<KpiChartWithAdapter
  configuration={configuration}
  dataModel={dataModel}
  dataAdapter={adapter}
/>
```

### Props

- `configuration: KpiChartConfiguration` — one metric, no dimension.
- `dataModel: KpiDataModel` — metrics only (no `dimensions` field).
- `dataAdapter: DataAdapter` — implementation that runs the query.
