**Apollo Vertex** is the design system for UiPath Vertical Solutions - customizable, industry-specific automation solutions built on the UiPath platform.

## Overview

The `@uipath/vs-core` package provides everything you need to build data-driven UiPath solutions:

- **UiPath SDK Integration**: Simplified APIs for working with UiPath Data Service entities and process executions
- **React Context Provider**: `SolutionProvider` for easy SDK initialization and data access
- **TanStack Query Collections**: Ready-to-use data collections with built-in caching and reactivity
- **TypeScript Types**: Full type safety for entities, processes, and configurations

## Getting Started

To create a new vertical solution, you have two options:

**Option 1: Use the UiPath CLI (Recommended)**

Install the `uipcli` tool and its vertical solutions plugin:

```bash
npm install @uipath/cli @uipath/vss
```

After installing, you can run commands via `uip`.

### `uip vss` commands

Vertical Solutions plugin for managing UiPath Vertical Solutions.

Also supports flags, for more info `uip vss --help` or `uip vss [command] --help`.

Plugin docs: https://github.com/UiPath/cli/tree/main/packages/vertical-solutions-tool

- **Initialize a new vertical solution**

```bash
uip vss init
```

- **Scaffold a new vertical solution**

```bash
uip vss scaffold
```

- **Add an entity, process, or connection**

```bash
uip vss add <type> [path]
```

- **Sync a vertical solution**

```bash
uip vss sync
```

- **Generate types for your vertical solution**

```bash
uip vss generate
```

**Option 2: Fork the Template**

Start with the [Vertical Solution Template](https://github.com/UiPath/vertical-solutions-template) for a pre-configured project structure.

Both options give you a ready-to-use project with `@uipath/vs-core` already installed and configured.

## Install Apollo Vertex

Apollo Vertex needs React 19.2+ and Tailwind CSS 4. Install the package:

<PackageInstall packages="@uipath/apollo-vertex" />

Your package manager won't install `@uipath/vs-core`, `@uipath/proteus-client` or `@tanstack/react-db` for you, so add them yourself if your project doesn't have them yet. The two UiPath packages are not on the public npm registry.

Import the stylesheet once from your app's CSS. It includes Tailwind and the Vertex theme:

```css
@import "@uipath/apollo-vertex/tailwind.css";
@source "./"; /* your own sources */
```

Then import components from the package:

```tsx
import { Button, DataTable } from "@uipath/apollo-vertex";
```

## Set up agent skills

Apollo Vertex ships [agent skills](https://agentskills.io) that tell coding agents such as Claude Code, Cursor and Copilot how to build UI with Apollo Vertex. For example, one skill tells the agent to use Vertex components instead of writing its own, and another lists which component fits each need, built from the [component pages](/components) of these docs. [TanStack Intent](https://tanstack.com/intent) finds these skills in your `node_modules` and points your agent at them.

Run this once from your project root:

```bash
npx @tanstack/intent@latest install
```

Run it in an interactive terminal. It asks which packages' skills your agent may load, saves your choice in `package.json`, and adds instructions to your agent config file (for example `AGENTS.md` or `CLAUDE.md`). Commit both files so everyone on the project gets the same setup.

The skills are versioned with Apollo Vertex, so updating it updates them too. You don't need to run `install` again.

To see the skills that are available, or to read one yourself:

```bash
npx @tanstack/intent@latest list
npx @tanstack/intent@latest load @uipath/apollo-vertex#use-vertex-components
```
