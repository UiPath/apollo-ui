# Side panel

A panel at the start or end edge of a template. The same surface fills both
panel slots.

## Purpose

Content that sits beside the page's main content: a work queue, secondary
navigation, the AI assistant, activity history, a source document.

## What it provides

| | |
| --- | --- |
| Shape | <Code>{sidePanelSurface.provides.orientation}</Code>: a column that grows downward. |
| Width | Set by the slot. The surface's own minimum is {sidePanelSurface.width.min}px. |
| Inner width | {sidePanelSurface.provides.width.min}px at the minimum when padded. On the Detail page: start {START_PANEL_WIDTH.default - 2 * PADDED_INSET_PX}px, end {END_PANEL_WIDTH.default - 2 * PADDED_INSET_PX}px at its default. |
| Padding | `padded` ({PADDED_INSET_PX}px) or `flush` |
| Scroll | `surface` (it scrolls and fades) or `occupant` (the occupant scrolls itself) |

## Configurations

- `side`: `start` or `end`.
- `padding` and `scroll`: from the occupant's specs.
- Placement and open state come from the template. See
  [choosing placement](/templates/detail-page#choosing-placement).
- Teams can't set the background. It follows placement.

## Appearance

- **Below header:** transparent over the Shell's ambient layer.
- **Beside header:** the `--side-panel-tint` background, `--sidebar` at
  {SIDE_PANEL_TINT_STRENGTH}%, over the ambient layer. The ambient layer still
  shows through.
- **Scroll fades:** a mask at an edge while there is more content that way. The
  mask fades the content, never the tint.
- **Dividers:** drawn by the template, not the panel.
- **Motion:** opening and closing take {PANEL_TRANSITION_DURATION_MS}ms, like
  the Shell sidebar.

## Accessibility

- It renders an `<aside>` landmark. Give it an `aria-label` that names its
  content.
- A closed panel is inert: it can't take focus and assistive tech skips it,
  even while it animates out. If focus was inside, it moves to main.
- The end panel's resize handle is a focusable separator named "Resize end
  panel", with its width in `aria-valuenow`, `aria-valuemin`, and
  `aria-valuemax`. Arrow keys follow start and end, so they flip in
  right-to-left languages.
- In forced-colors mode the dividers become real borders in `CanvasText`.
- Reduced motion turns the open and close animation off.

## When not to use

- For the page's main content. Use the [content area](/surfaces/content-area).
- For a short, one-off task, like a confirmation or a quick edit. Use a dialog
  or a sheet.
- To add emphasis. Placement shows what the content belongs to, not how
  important it is.

## Known gaps

- **Small screens.** There is no overlay surface yet. On narrow windows panels
  close instead.
- **Panel triggers.** There are no in-page controls to open or close panels
  yet.
- **Start panel resizing.** The start panel isn't resizable yet.
