customer support. It shows the same information in either shape, so it's one
occupant with both orientations.

## View model

It renders a `KeyFactsViewModel`. Nothing in it names a domain.

| Field | What it holds |
| --- | --- |
| `subject` | What the facts are about, for accessible names, like an item's id |
| `facts` | Each fact's `id`, `label`, and `value`, already formatted. A missing or empty value shows as "Not set" |

Your solution's adapter decides which few facts matter, and formats them.

## States

It renders the standard occupant states. With no facts, it shows the empty
state.

## Installation

```bash
npx shadcn@latest add @uipath/key-facts
```

## Accessibility

- The facts are a description list, named for the subject ("Key facts for …").
- Long labels truncate, with the full label in a title. Values wrap, so
  nothing is cut off at any width from the minimum up.
