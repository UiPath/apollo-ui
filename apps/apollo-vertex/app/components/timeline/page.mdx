# Timeline

Primitives for building an activity timeline: a status marker (the dot) and the row layout (the connecting line and dot slot a row sits in). Together they render a mixed trail of human and agent steps, without knowing anything about your domain.

The marker takes a plain `variant`, so a solution maps its own states onto the shared set and keeps that mapping on its side. See [AI Toolkit](/guidelines/ai-toolkit#timeline-markers) for the color and expression principles this follows.

## Markers

Nine variants cover human and agent steps: people, completed steps, queued and suspended work, a spinning in-progress ring, and failed, cancelled, and done outcomes. Each comes in a full and a compact size.

## In a row

## Usage

```tsx
import { TimelineMarker, TimelineRowLayout } from "@/components/ui/timeline"
```

```tsx
<ol>
  {events.map((event, index) => (
    <li key={event.id}>
      <TimelineRowLayout
        isLast={index === events.length - 1}
        marker={<TimelineMarker variant={event.variant} initials={event.initials} />}
      >
        <p className="text-sm font-medium">{event.title}</p>
      </TimelineRowLayout>
    </li>
  ))}
</ol>
```

Keep the domain mapping on your side: convert your own state into a `TimelineMarkerVariant` before rendering, so the timeline stays free of domain concepts.

## TimelineMarker props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `TimelineMarkerVariant` | — | Required. One of `user`, `completed-user`, `completed-ai`, `ai-upcoming`, `ai-suspended`, `ai-progress`, `ai-failed`, `ai-cancelled`, `ai-complete`. |
| `initials` | `string` | `"?"` | Shown inside the `user` marker. Ignored by other variants. |
| `compact` | `boolean` | `false` | Render the smaller size for dense trails. |

## TimelineRowLayout props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `marker` | `ReactNode` | — | Required. The marker rendered in the dot slot, typically a `TimelineMarker`. |
| `children` | `ReactNode` | — | Required. The row content beside the marker. |
| `isLast` | `boolean` | — | Required. Drops the connecting line on the final row (full rows fade it out instead). |
| `compact` | `boolean` | `false` | Tighten the gap and line spacing to match compact markers. |
