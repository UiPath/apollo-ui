# Installation

Apollo v.4 is UiPath's open-source design system for building consistent user experiences across all UiPath products.

**GitHub:** [UiPath/apollo-ui](https://github.com/UiPath/apollo-ui)

---

## Choose Your Package

Apollo is split into focused packages. Pick the one that matches what you're building.

### `@uipath/apollo-core`

The shared foundation — design tokens, fonts, and CSS variables. Both Apollo Wind and Apollo React depend on this package. Install it directly only if you need tokens without a component library.

**Best for:** Custom builds that need design tokens or fonts without a full component library.

**Install**

```bash
npm install @uipath/apollo-core
```

**Run locally**

```bash
pnpm build
```

### `@uipath/apollo-ui-icons`

The Apollo icon set — 1300+ SVG icons, importable as modules or as raw assets. Icon names and the `IconName` union are available from `@uipath/apollo-ui-icons/types` without pulling any SVG in.

`@uipath/apollo-core/icons` still re-exports this package, but that path is deprecated and will be removed in the next major.

**Best for:** Any project that needs Apollo icons as raw SVG, without React. React users get ready-made components from `@uipath/apollo-ui-icons-react` instead.

**Install**

```bash
npm install @uipath/apollo-ui-icons
```

**Use**

```ts
import { Close, AddComment } from '@uipath/apollo-ui-icons';
import closeSvg from '@uipath/apollo-ui-icons/svg/close.svg';
import { type IconName, iconNames } from '@uipath/apollo-ui-icons/types';
```

### `@uipath/apollo-ui-icons-react`

The Apollo icon set as React components, generated from `@uipath/apollo-ui-icons`. Each icon is a `forwardRef` `<svg>` with a `size` prop for width and height, defaulting to the source SVG's size (24 for most icons). Single-color icons paint with `currentColor` and take the parent's text color; logos and most activity icons keep their own colors. `@uipath/apollo-react/icons` re-exports this package.

**Best for:** React projects that need Apollo icons. Requires React 18.3 or later.

**Install**

```bash
npm install @uipath/apollo-ui-icons-react
```

**Use**

```tsx
import { AddComment, Close } from '@uipath/apollo-ui-icons-react';
import Lock from '@uipath/apollo-ui-icons-react/Lock';

<Close />
<AddComment size={16} className="text-muted-foreground" />
<Lock />
```

### `@uipath/apollo-wind`

The modern UI component library for rapid prototyping and new product interfaces. Built with Tailwind CSS and shadcn/ui — includes 60+ components, page templates, and full theming support.

**Best for:** Prototyping, new product UIs, and any project using Tailwind CSS.

**Install**

```bash
npm install @uipath/apollo-wind
```

**Run locally** (after cloning the monorepo and running `pnpm install`)

```bash
pnpm build
pnpm storybook:dev
```

</div>
<div>

### `@uipath/apollo-react`

The component library for UiPath workflows and automation products. Built on Material UI with Apollo theming — provides the components and patterns used across workflow-based experiences.

**Best for:** Workflow interfaces, automation products, and existing Material UI projects.

**Install**

```bash
npm install @uipath/apollo-react
```

**Run locally**

```bash
pnpm build
pnpm storybook:dev
```
